# SleepStage AI: Polysomnography-Aligned Wearable Signal Modeling for Sleep Stage Classification

SleepStage AI is a research-oriented machine learning project for sleep-stage classification using wearable physiological signals aligned with polysomnography-labeled sleep-stage epochs.

The project analyzes heart rate, motion, and step-count signals from public sleep-study data and implements an end-to-end workflow covering data ingestion, timestamp alignment, 30-second epoch construction, feature engineering, exploratory analysis, dimensionality reduction, supervised learning, and model evaluation.

## Project Focus

- PSG-aligned sleep-stage classification
- Wearable physiological signal modeling
- Heart rate, motion, and step-count feature analysis
- Random Forest and Logistic Regression baselines
- PCA-based exploratory analysis
- Confusion matrix and classification report evaluation
- Reproducible notebook-based research workflow
