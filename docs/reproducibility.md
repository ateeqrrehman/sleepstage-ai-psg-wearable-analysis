# Reproducibility

## Environment

The repository is designed for Python 3.11 environments with dependencies listed in `requirements.txt`.

## Dataset Access

Data is retrieved from the public PhysioNet Sleep-Accel dataset.

## Reproducibility Practices

- Deterministic model random states
- Modular preprocessing pipeline
- Reusable feature-engineering functions
- Public dataset references
- Notebook walkthrough for research traceability
- Source modules for reusable execution

## Future Improvements

- Environment containerization
- Experiment tracking
- Automated evaluation reports
- Dataset version locking
