# Research Report

## Overview

This document summarizes the research workflow, experimental framing, feature engineering strategy, and supervised learning methodology used in SleepStage AI.

## Research Goal

The project investigates whether wearable physiological signals aligned with PSG sleep-stage labels contain sufficient structure to support machine learning classification of sleep stages.

## Signals Used

- Heart rate
- Wrist accelerometry
- Step count
- PSG-aligned sleep-stage labels

## Modeling Workflow

1. Data ingestion
2. Timestamp normalization
3. Epoch assignment
4. Feature engineering
5. Exploratory visualization
6. Statistical comparison
7. PCA analysis
8. Random Forest classification
9. Logistic Regression baseline
10. Evaluation and interpretation

## Evaluation

Evaluation focuses on confusion matrices, accuracy, per-class metrics, and feature-importance analysis.
